# Проект "Интернет-магазин"

Учебный проект в рамках курса Python. Реализована объектно-ориентированная модель интернет-магазина с возможностью добавления товаров, категорий и оформления заказов.

## Реализованный функционал:
*   **Базовые классы**: `Product` (товар) и `Category` (категория).
*   **Магические методы**: `__str__` для строкового отображения, `__add__` для сложения стоимости товаров на складе.
*   **Инкапсуляция**: Приватные атрибуты цены и списка товаров, геттеры и сеттеры с проверками.
*   **Наследование**: Классы `Smartphone` (смартфон) и `LawnGrass` (газонная трава), унаследованные от `Product`.
*   **Абстракция**: Базовый абстрактный класс `BaseProduct`.
*   **Миксины**: Класс `ReprMixin` для автоматического вывода информации об объекте при его создании.
*   **Дополнительные классы**: `Order` (заказ) и `CategoryIterator` (итератор для перебора товаров).
*   **Ограничения**: Валидация типов при сложении товаров и добавлении их в категорию.
*   **Тестирование**: Покрытие кода тестами (pytest) составляет более 75%.
